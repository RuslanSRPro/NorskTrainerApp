# D10: «Перевірити» узнаёт формы слова

Согласовано 23.10.2026. Ставится после D10_translation_cards_v1. Меняется только приложение, база и функции не трогаются.

## Что было

«Перевірити» искал слово только по лемме и заголовку. «tok», «er», «brennen» не находились («Немає в базі: tok»), хотя при разборе текста эти формы узнаются.

## Что стало

Для каждого введённого слова:
1. как раньше — карточки с такой леммой или заголовком;
2. **дополнительно** — карточки, у которых это слово есть среди форм. Используются те же таблицы, что и при разборе текста:
   - формы Ordbøkene (`lexeme_form_display_v2`, Bokmål);
   - формы составного слова по главной части;
   - формы NAOB.

- Сначала идут совпадения по лемме, потом по форме, без повторов.
- В списке строка по форме показывается так: **«tok → ta — дієслово · брати»**.
- «var» теперь даёт и прилагательное, и существительные var, и **var → være**.
- Карточки читаются тем же способом, что и в обычном поиске, поэтому список, превью и карточка совпадают.
- Если таблица форм не читается, поиск по ней просто ничего не добавляет. Поиск по лемме работает как раньше.
- То же относится к обновлению списка после задачи и к открытию слова из анализа.
- Режим Аудит отправляет в задачу введённые слова, как и раньше.
