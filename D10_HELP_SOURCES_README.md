# D10: справка по звёздам и источникам + часть речи на языке приложения (v2)

Согласовано 16.10.2026. Ставится **после** D10_homonym_icon_v2. Только приложение.

## Справка (окно 💡), когда у слова есть оценка сервера

1. **Название и описание уровня по звёздам.** Прежние «Dictionary match» и «Usage evidence» — это названия старых уровней, поэтому они заменены:

   | ★ | Название (укр.) | Описание |
   |---|---|---|
   | 5 | Навчальний словник | Є стаття в Ordbøkene для цієї частини мови |
   | 4 | Два словники | Стаття NAOB і запис у Lexin або Wiktionary |
   | 3 | Один словник | Підтверджує один словник (NAOB, Lexin або Wiktionary) |
   | 2 | Згадка | Лише згадки, окремого запису немає |
   | 1 | Не підтверджено | Словники не підтвердили (переклад від ШІ) або ще не перевірено |

2. **Постоянный список из пяти источников**, всегда в одном порядке: Ordbøkene, NAOB, Lexin, Wiktionary, Språkrådet. В каждой строке:
   - что дал источник;
   - у Ordbøkene — номер статьи;
   - если источник знает слово только в другой части речи — какой: «лише як: дієслово».
3. **Прежний список доказательств** не удалён, он свёрнут под строкой «Подробиці / Details / Detaljer» и открывается по нажатию.

Без оценки сервера окно выглядит как раньше.

## Прокрутка окон (v2)

Окно справки 💡 и окно омонимов плохо прокручивались. Причина: окно было «нажимаемым» (`Pressable`) и перехватывало жесты прокрутки. Теперь окно — обычный блок, а закрытие по нажатию вне окна делает отдельный слой под ним. Кнопка «Закрыть» работает как раньше.

## Read

- «Velg ordklasse» был написан только по-норвежски. Теперь: «Оберіть частину мови / Choose part of speech / Velg ordklasse».
- Часть речи в выборе («passe — прикметник») и в разделе омонимов показывается на языке приложения. Перевод там и раньше брался по языку приложения.
