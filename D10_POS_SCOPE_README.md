# D10 шаг Б, часть 1: часть речи в ответе каждого источника

Согласовано 15.10.2026. Ставится **поверх** D10_compound_v1 и D10_ordbokene_cache_v1. Миграции нет.

Эта часть только **собирает** доказательства по части речи. Уровень (звёзды) пока считается по-старому. Новый расчёт будет в части 2: сервер, по согласованной таблице. Для неё нужен файл запроса 130.

## Что меняется

К ответу источника добавляются четыре поля. Старые поля (`found`, `quality`, `registered_entry`…) не меняются, кроме одного согласованного случая с Wiktionary (см. ниже).

| Поле в `evidence` | Значение |
|---|---|
| `requested_pos` | часть речи карточки (noun, verb…) |
| `found_pos` | какие части речи источник показывает для этого слова |
| `pos_match` | `match`: есть часть речи карточки;<br>`mismatch`: слово есть, но только с другими частями речи;<br>`unknown`: слово есть, части речи не видно;<br>`not_applicable`: выражение или часть речи не передана |
| `pos_basis` | откуда часть речи |

## Где источник берёт часть речи

| Источник | Как |
|---|---|
| **Lexin** | категория статьи (`E-kat`), только у статей с точно этой леммой. Если в укр. словаре части речи карточки нет, спрашивается и норв. словарь Lexin. Это один лишний запрос, только в этом случае |
| **Wiktionary** | заголовки частей речи в разделе **Bokmål**:<br>no.: «Norsk» / «Bokmål»;<br>en.: «Norwegian Bokmål». Раздел Nynorsk не считается |
| **NAOB** | заголовок статьи («tid &#160; substantiv»);<br>или строка результата поиска «лемма + часть речи» («huske substantiv»). Слово, которое только упоминается в описаниях, части речи не даёт, это `unknown` |
| **Ordbøkene** | уже ищет по части речи. Найдено → `match` |
| **Språkrådet** | части речи нет, всегда `unknown`. По согласованию не засчитывается |

## Согласованное изменение старого поведения

1. **Wiktionary, только Bokmål.** Раньше страница засчитывалась, если на ней где угодно было слово «nynorsk» или «norsk». Теперь нужен раздел Bokmål. Слово только из нюнорска → `not_found`. Если заголовки страницы не читаются, остаётся старое правило.
2. **Попутно:** en.wiktionary раньше **никогда** не засчитывался: искал разметку `== Norwegian Bokmål ==`, которой нет в готовой странице. Теперь его раздел Bokmål засчитывается так же, как no.

## Проверено

- **12 тестов Node** на ответах в форме настоящих. Тексты NAOB взяты из живых доказательств tid / huske / være.
  - **brenne:**
    - Lexin, Wiktionary и NAOB показывают только глагол;
    - карточка-существительное → `mismatch`, глагол → `match`;
    - раздел Nynorsk с существительным не засчитан.
  - **drikke:** у Lexin есть глагол и существительное → существительное `match`.
  - **like:** прилагательное `match`; likevel не путается с like.
  - **Lexin:** укр. словарь — только глагол, норв. словарь — существительное → `match` из норв. словаря.
  - **NAOB:** слово только упоминается на странице поиска → `found` как раньше, части речи нет (`unknown`).
  - **lexical-worker:**
    - часть речи карточки доходит до Lexin;
    - поля попадают в `evidence`;
    - Språkrådet → `unknown`, выражение → `not_applicable`.
- **Сравнение со старыми адаптерами на 27 случаях:** найдено, качество, флаги, ссылки и подписи совпадают. Ссылка и подпись Lexin меняются только тогда, когда ответ взят из второго словаря.
- **Синтаксис**, проверка повторных объявлений. Окончания строк исходных файлов сохранены.
