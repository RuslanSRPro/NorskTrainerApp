# D10 шаг Б, часть 3: приложение показывает звёзды сервера

Согласовано 16.10.2026. Ставится **после** D10_verification_stars_v1 (миграция должна быть выполнена). Только приложение, деплой функций не нужен.

## Что меняется

Одна оценка — серверная. Звёзды, цвет значка, точка у слова в Read и порядок по уровню берутся из `verification_stars_v1`:

| ★ | Цвет |
|---|---|
| 5 | зелёный |
| 4 | синий |
| 3 | жёлтый (промежуточный) |
| 2 и 1 | серый: серая карточка |

Если у слова нет серверной оценки (предпросмотр слова не из базы или таблица недоступна), остаётся прежний расчёт приложения. Ошибка чтения ничего не ломает.

## Справка (окно по нажатию на 💡)

Добавлены блоки:
- **«Сіра картка»** (1–2★). Слово есть в базе и в обучении, но словари ещё не подтвердили его для этой части речи. Уровень поднимется после новой проверки.
- **«Ще не перевірено»**. Карточка ещё не проходила проверку словарями: доказательств нет, будут после полного аудита.
- **«Немає в навчальному словнику Ordbøkene»** (3–4★ без статьи Ordbøkene).
- **«Що дало кожне джерело»**: часть речи карточки и строка на каждый источник:
  - стаття цієї частини мови;
  - є лише як інша частина мови — не враховано;
  - лише згадка;
  - Språkrådet: згадка, не більше 2★;
  - немає.

Прежний список доказательств остаётся под этими блоками без изменений. Тексты на украинском, английском и норвежском.

## Проверено

- Синтаксис, проверка повторных объявлений, проверка типов изменённых файлов.
- **Тест чтения:**
  - два id → один запрос;
  - неверный id не запрашивается;
  - слово без оценки → прежний расчёт.
- **Звёзды 2 у сервера** → 2★ при доказательствах на 5★ по старому расчёту; 3★ → жёлтый; неверное значение → прежний расчёт.

## Порядок

1. Установка:
   ```powershell
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\D10_app_server_stars_v1.zip" -DestinationPath "$env:USERPROFILE\Downloads" -Force
   ```
   ```powershell
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\D10_app_server_stars_v1\install_d10_app_server_stars.ps1"
   ```
2. Проверка сборки, ошибок быть не должно:
   ```powershell
   npx expo export --platform android
   ```
3. Обновление приложения: `eas update`, как обычно.
4. **В приложении**, Read, открыть карточку и нажать 💡:
   - brenne (глагол) → 5★, зелёный;
   - vinterjakke → 3★, жёлтый, «Немає в навчальному словнику Ordbøkene», NAOB: стаття;
   - слово с 1–2★ → блок «Сіра картка».

## Откат

Вернуть 4 файла из `*.d10-app-stars.bak`, удалить `services/serverStars.ts`, обновить приложение.
