# D10 шаг Б, пункт 4: клон части речи без своей статьи — серая карточка

Согласовано 15–16.10.2026. Ставится **после** D10_verification_stars_v1.

## Что было

Задача создаёт копию слова для другой части речи, которую нашла в доказательствах. Пример: brenne (сущ.) рядом с глаголом. Если для этой части речи нет своей статьи Ordbøkene, копия останавливалась на допуске (`admission_gate`). Задача заканчивалась статусом «нужна ручная проверка».

## Что меняется

1. **Новая функция `d10_promote_gray_pos_clones_v1(задача)`.** Она делает из такой копии карточку.
   - Если карточка (лемма, часть речи, без ключа омографа) уже есть, копия привязывается к ней. Иначе создаётся новая.
   - Карточка получает свежие доказательства этой задачи и статус `candidate` / `ai_candidate`.
   - Звёзды по таблице: обычно 1–2★, серая. Если у Lexin есть эта часть речи — 3★.
   - Копия идёт в обогащение, как любая карточка: переводы, ИИ.
   - Формы не выдумываются: у слова без статьи их нет.
   - Только части речи, которые пропускают правила допуска (сущ., глагол, прил., наречие). Правила служебных слов действуют.
   - Повторный вызов ничего не меняет.
2. **`d10_job_gray_family_audit_v1`** (прежний код плюс дополнение):
   - серые карточки-копии считаются серыми, полноту форм у них не проверяют;
   - копия, оставшаяся на допуске (например, determiner), больше не останавливает задачу;
   - **не меняется:** правило семейства, правило служебных слов, все прежние поля ответа;
   - новое поле ответа: `gray_pos_clone_count`.
3. **`job-orchestrator`.** После продвижения и шага омографов вызывается функция из п. 1. Если она упадёт, задача не падает: копия просто остаётся серым кандидатом.

Обычные слова (не копии), которые не прошли допуск, по-прежнему останавливают задачу, как раньше.

## Проверено (PostgreSQL 16, функция допуска с живой базы)

- brenne (сущ., конфликт части речи) → создана серая карточка, переход в обогащение.
- drikke (сущ., старая карточка уже есть) → привязан к ней, свежие доказательства, статус `candidate`.
- som (determiner) → не допущен правилами, остаётся на допуске, задачу не блокирует.
- bort (обычное слово, не копия) → блокирует, как раньше.
- Блокирующих было 4, стало 1 (bort).
- Повтор вызова: 0 изменений. Повтор миграции: без ошибок.
- Синтаксис `job-orchestrator`, проверка повторных объявлений.
