# D10: аудит переписывает старые AI-переводы

Основа: установленный D10_ai_no_article_v1. Меняется один файл, `ai-enrichment-worker/index.ts`.

## Что было

У слов из прошлых итераций (fødselsdato, vinterjakke, julelys и др., 25–30.09):
- AI-перевод **без доказательства**: нет проверки второй моделью, нет привязки к статье;
- иногда по 2 варианта, по старому правилу.

AI заполняет только то, чего нет. Такой перевод считался «есть», поэтому аудит его не трогал. Проверка полноты при этом его не засчитывала.

## Что меняется

У лексемы AI-перевод или AI-пример **без действующего доказательства** считается отсутствующим, и AI делает его заново по текущим правилам:
- есть своя статья → по статье;
- статьи нет → по пути «без статьи», с «≈».

При записи старые AI-строки этого языка удаляются: так уже работает запись. Поэтому лишние вторые варианты тоже уходят.

**Не трогается:**
- AI-строки с действующим доказательством (текущая версия, проверка принята). Повторной оплаты нет.
- Переводы Lexin и ручные.
- Выражения: их AI-переводы без доказательства по устройству.

**Если AI или проверка второй моделью не прошли** (например, сбой Ordbøkene), старые строки остаются как были. Ничего не теряется.

Без статьи AI делает только переводы. Старый AI-пример такого слова остаётся в базе. На полноту он не влияет.

## Цена

Один AI-вызов на каждое слово со старым AI-переводом, один раз. Сколько таких слов в базе, покажет запрос в конце.

## Проверено

Тест на копии воркера с заглушками, 4 из 4:
- старые строки → «нет»;
- действующие → «есть»;
- Lexin → «есть»;
- выражения не затронуты.

Синтаксис проверен.

## Порядок

1. Установка, каждая команда отдельно:
   ```powershell
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\D10_ai_audit_rewrite_v1.zip" -DestinationPath "$env:USERPROFILE\Downloads" -Force
   ```
   ```powershell
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\D10_ai_audit_rewrite_v1\install_d10_ai_audit_rewrite.ps1"
   ```
2. Деплой:
   ```powershell
   npx supabase functions deploy ai-enrichment-worker
   ```
3. Тест: режим Audit → `vinterjakke` → Check → ✅. Затем тот же запрос по переводам этих 7 слов. У vinterjakke ожидается один uk и один en, `ev_status = ai_reviewed_no_article`, а в приложении «≈».

## Откат

Вернуть файл из `*.d10-audit-rewrite.bak`, задеплоить ai-enrichment-worker.
