# D10: режим Read — слово не в базе → предпросмотр из словарей

Согласовано 15.10.2026:
- поиск только по нажатию на слово, по одному запросу;
- перевод из Lexin, если он там есть.

Ставится **поверх** D10_compound_v1. Миграции нет.

## Как работает

1. В Read нажатие на красное слово («Not in database») или «Check» для слова, которого нет в базе. Как и раньше, сначала ищется база.
2. **Новое:** если в базе слова нет, функция `read-word-preview` ищет его:
   - **Ordbøkene:** точная лемма, иначе словоформа (bøkene → bok). Из статьи берутся:
     - лемма и часть речи;
     - формы, выбранные тем же правилом, что и в цепочке форм;
     - артикли en/ei/et;
     - первые три толкования на норвежском.
   - **Lexin:** перевод uk/en по лемме, если он там есть.
3. Открывается карточка-предпросмотр с формами, переводом Lexin и толкованиями. Строка источника объясняет, откуда данные: «З Ordbøkene і Lexin, ще не в базі» / «Немає в Ordbøkene…» / «Ordbøkene зараз недоступний».
4. Кнопка «➕ Додати preview у базу» отправляет слово тем же путём, что «Сохранить в базу» в Read: задача → проверка, обогащение → слово в изучении. После задачи карточка слова открывается из базы. Раньше эта кнопка всегда давала ошибку: после удаления `enrich-word` она стала заглушкой.

**Ничего не пишется**, пока не нажата кнопка «➕ Додати preview у базу». AI не вызывается. Если словарей нет или они не ответили, Read работает как раньше.

## Проверено

- **5 тестов Node** с подставными ответами словарей:
  - bok: две статьи, главная первой;
  - формы boken (+boka), артикли en/ei, толкование;
  - Lexin: книга / книжка, book;
  - словоформа bøkene → bok по поиску форм, Lexin спрошен по лемме;
  - нет ни в одном словаре;
  - Ordbøkene 502 и Lexin 500 → статусы ошибок без падения.
- **Синтаксис** всех файлов.

## Порядок

1. Установка:
   ```powershell
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\D10_read_preview_v1.zip" -DestinationPath "$env:USERPROFILE\Downloads" -Force
   ```
   ```powershell
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\D10_read_preview_v1\install_d10_read_preview.ps1"
   ```
2. Тест (ожидается `pass 5`):
   ```powershell
   node --experimental-strip-types --test supabase/functions/tests/d10-read-preview/read_preview_test.mts
   ```
3. Деплой:
   ```powershell
   npx supabase functions deploy read-word-preview
   ```
4. Приложение: `eas update`.
5. Тест в Read, например на тексте с новым для базы словом (для проверки форм — существительное в форме множественного числа). Нажать на красное слово. Ожидается:
   - предпросмотр с леммой, формами, переводом Lexin и строкой источника;
   - в базу ничего не записано, пока не нажата кнопка «➕ Додати preview у базу».

## Откат

Вернуть `services/api.ts` и `app/(tabs)/reading.tsx` из `*.d10-read-preview.bak`, обновить приложение. Функцию `read-word-preview` можно оставить: её никто не вызывает.
