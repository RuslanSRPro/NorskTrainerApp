# D10: вторая карточка только по доказательствам, серая привязка не меняет карточку, bære II скрыта

Согласовано 20.10.2026 по ревью от 17.10. Ставится **после D10_translation_cards_v1**.

## 1. Серая привязка никогда не меняет существующую карточку

Раньше клон части речи или слово с несколькими статьями Ordbøkene перезаписывали свидетельства уже существующей карточки той же леммы и части речи и ставили ей `ai_candidate`. Это могло понизить подтверждённую карточку, даже без привязанной статьи.

Теперь на **всех** путях:

| Ситуация | Что происходит |
|---|---|
| Карточка этой леммы и части речи есть | элемент привязывается к ней (главная первой); **карточка не меняется** |
| Карточки нет, это клон или несколько статей Ordbøkene | новая серая карточка, как раньше |
| Карточки нет, и это не тот случай | элемент остаётся на проверке, как раньше |

- Серость хранится у элемента задачи (`promoted_gray`, `gray_path`). Уровень карточки меняется только её собственным правилом повышения.
- Проверено на базе: подтверждённая карточка (статья, `verified`) после привязки клона осталась прежней.
- Миграция останавливается, если текущая функция отличается от версии D10_translation_cards_v1.

## 2. Вторая карточка (R9) только при двух положительных доказательствах

Раньше отсутствие форм принималось за «другие формы». bære II (статья 8440: `VERB Uninfl`, только «bære», в теле только вложенное выражение «trøste og bære») стала отдельной карточкой с 0 переводами.

Теперь статья другой парадигмы даёт вторую карточку, только если у неё:
- **собственные формы:** не `Uninfl` и не одна лемма;
- **собственное значение:** хотя бы одно своё объяснение, не только вложенные выражения или ссылки.

Если чего-то нет, решение `skipped` с пометкой «на проверку» (`r9_guard_no_own_forms` / `r9_guard_no_own_meaning`). Карточка не создаётся, статья видна в запросе 112. Это не значит, что статья совпадает с основной.

Остальные правила не менялись:
- одинаковые формы → R8;
- то же значение, что у основной → проверка.

være III (свои формы и своё значение) по-прежнему даёт вторую карточку.

## 3. bære II скрывается, ничего не удаляется

- **154** (только чтение): все таблицы, которые ссылаются на карточку, включая прогресс пользователя и выражения.
- **154b**: карточка получает `dictionary_status = 'excluded'`, причину `d10_r9_false_card_no_own_forms_8440` и `is_learning_lexeme = false`.
  - Прежние значения сохраняются в `private.d10_hidden_cards_v1`.
  - Карточка, привязка к статье 8440, решение шага омографов и все связи остаются.
  - 154b **останавливается**, если на карточку ссылается таблица прогресса приложения (имя с progress / user / learn / srs).
- **154c** возвращает всё как было (только по просьбе).
- Шаг омографов больше **не добавляет скрытые** вторые карточки в новые задачи.
- В поиске и иконке омонимов скрытая карточка не показывается: они уже фильтруют по этим полям.
