## Контекст для ИИ
- Слово со своей статьёй: определения и примеры только этой статьи этой части речи; «jf. X» → `see_also` (D11).
- Несколько статей, карточка привязана к одной → её статья (`boundArticleContext`).
- «≈»-пути: привязка NAOB (определение статьи NAOB) / нет статьи (NAOB, Lexin, Wiktionary, Lexin_ru) / статья без
  толкования (каскад NAOB → Wiktionary → Lexin → ничего). Запрещено для второй карточки-омонима и группы омонимов.
- Омонимы: ограничение «не повторять переводы соседей, уточнение в скобках» (не источник смысла).
- Выражение: свои толкования Ordbøkene / NAOB; без толкования — «≈», если подтверждено целиком или синоним NAOB (D9).

## Генерация и проверка (D10)

причиной отказа, OpenAI проверяет. Попытка 2 не прошла только по примеру → попытка 3: только перевод (слова).
