# 02 — Части речи: клоны, деление нового слова

## Назначение
Слово с несколькими частями речи превращается в отдельные пункты по каждой части речи.

## Код
SQL `public.expand_multi_pos_occurrences_for_job(job)` [живой текст: последняя редакция в
`20261013200000_d10_text_context_pos_clones_v1` + патч `20261111120000_d10_missing_pos_split_v1`].
Вызывается из job-orchestrator до продвижения; после — ждёт, пока клоны пройдут проверки.

## Логика [проверено]
- Части речи из evidence: `extract_all_pos_from_source_evidence(evidence, lemma)`.
- Пункт без части речи + одна точная статья Ordbøkene (strong, 1 кандидат) → берёт её часть речи (`d10_exact_article_v1`).
- Пункт без части речи + несколько частей речи → (с 11.11) берёт первую, проверки перезапускаются, остальные — клоны
  (`pos_source='missing_pos_split'`). До 11.11 такой пункт застревал `unknown_pos_requires_review` (stemme).
- Пункт с частью речи → клоны для остальных (noun / verb / adjective / determiner).
- Текстовая задача, часть речи выбрана правилом контекста → клонов нет (R2/R3); без сигнала — все части речи.
- Клон: `clone_reason='multi_pos_evidence_expansion_known_pos'`, свои pending-проверки (копии).
