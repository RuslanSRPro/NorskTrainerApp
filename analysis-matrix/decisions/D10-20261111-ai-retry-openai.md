# D10-20261111 — повтор ИИ для слов через OpenAI

**Решение:** первая попытка — Gemini (`gemini-2.5-flash-lite`) генерирует и проверяет. Если проверка отклонила
перевод слова — один повтор: OpenAI `gpt-6-luna` генерирует (с причиной первого отказа) и проверяет по тем же
правилам проверки. Выражения — OpenAI всегда (было и раньше).

**Почему:** лёгкая модель проверки отклоняла верные переводы из-за придирки к синониму (hete II «гріти»);
у выражений такая подстраховка давно работала.

**Цена / риск:** GPT вызывается только при отказе Gemini. Риск «модель сама генерирует и сама одобряет» проявился
на si (сущ.) «десятка» — причиной был неверный контекст («jf. ti» как толкование, C-1111-11), а не повтор. Следить.

**Связанное:** защита записи принимает `gemini` и `openai` (C-1111-02); причина отказа не стирается перед повтором.
