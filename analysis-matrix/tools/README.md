# tools

Будущие скрипты матрицы:
- выгрузка живых функций / cron / индексов в `db-live/` (из SQL-редактора или через Supabase CLI);
- проверка, что каждая строка `matrix.csv` ссылается на существующий файл / функцию.
Повторяемые диагностические запросы (номера 442, 443, 452, 454, 460, 461, 463, 464) лежат в «Загрузках» пользователя.
