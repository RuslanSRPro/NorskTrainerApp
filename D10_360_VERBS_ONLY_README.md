# D10: семья 360 только у глаголов (v2)

**v2:** в v1 обёртка называлась `Lexeme360Content`, а функция с таким именем в файле уже была. Сборка `eas update` падала с «Identifier 'Lexeme360Content' has already been declared». Обёртка переименована в `Lexeme360Main`, остальное без изменений. Установщик принимает и исходный файл, и файл из v1. Все изменённые сегодня файлы приложения дополнительно проверены компилятором TypeScript на повторные имена.

Согласовано 15.10.2026: «Показывать 360 только у глаголов, как задумано изначально. Выражения существительных оставить в базе просто как выражения».

## Что меняется

Только показ в приложении, один файл: `components/Lexeme360.tsx`.

| Часть речи карточки | 360 |
|---|---|
| глагол (`verb`, `verb_…`), выражение | показывается, как раньше |
| существительное, прилагательное, наречие и др. | не показывается |
| часть речи не указана | как раньше (показывается) |

Правило проверяется внутри `Lexeme360` и `Lexeme360Sheet`, поэтому действует везде, где они используются: экран чтения (карточка и окно 360) и тренировка (`TrainingMeta`).

Не меняется:
- привязки выражений к карточкам. Они нужны для допуска выражений к изучению;
- выражения существительных — они остаются в базе обычными выражениями;
- данные 360 и счётчики.

## Проверено

- **3 теста:** правило берётся прямо из файла.
  - verb, verb_phrase, expression → 360 показывается;
  - noun, noun_masculine, adjective, adverb, determiner → не показывается. «adverb» не путается с «verb»;
  - без части речи → показывается, как раньше.
- **Синтаксис** проверен. Хуки React не нарушены: проверка стоит в обёртке до внутреннего компонента.
