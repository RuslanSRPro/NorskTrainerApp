# D10: иконка омонимов v2 + серая копия до шага омографов (passe, прил.)

Ставится **после** D10_gray_pos_clone_v1 и D10_homonym_icon_v1.

## 1. Почему упала задача (passe, прилагательное)

- Слово «passer» в тексте дало глагол passe и копию «прилагательное».
- У Ordbøkene два прилагательных passe с **разными** формами:
  - passe I — не изменяется;
  - passé / passe II — формы passee.
  По правилу R9 это две карточки.
- Шаг омографов умеет делать именно это: даёт основной карточке статью с наименьшим номером (I) и создаёт вторую карточку (II).
- Но серая карточка для копии создавалась **после** шага омографов. Шаг её не видел, карточка осталась без статьи. Формы и ИИ упали: «две статьи, ни одна не выбрана».

**Исправление.** В `job-orchestrator` серая карточка теперь создаётся сразу после продвижения, **до** семейства и шага омографов. Код шага перенесён без изменений.

## 2. Иконка омонимов (согласовано 16.10)

- **Иконка.** Фиолетовый кружок «A¹²», рядом число — сколько всего карточек у этого слова. Появляется, только если других карточек больше нуля.
- **Порядок справа налево:** 💡 справка → 360 → омонимы. Синонимы потом встанут левее.
- **Список.** Строки «слово — часть речи · перевод», на языке интерфейса.
- **По нажатию на строку** открывается Read с полной карточкой, как из поиска. В `reading.tsx` добавлено только открытие карточки по ссылке `openLexemeId`.

## Порядок

1. Установка:
   ```powershell
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\D10_homonym_icon_v2.zip" -DestinationPath "$env:USERPROFILE\Downloads" -Force
   ```
   ```powershell
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\D10_homonym_icon_v2\install_d10_homonym_icon_v2.ps1"
   ```
2. Деплой:
   ```powershell
   npx supabase functions deploy job-orchestrator
   ```

   ```powershell
   npx expo export --platform android
   ```
4. Обновление приложения, как обычно.
5. Тест: текст со словом «passer». Ожидается:
   - задача без ручной проверки;
   - карточки passe (глагол), passe (прил.) со статьёй I и passe II (прил.).
