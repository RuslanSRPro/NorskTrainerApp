# D10 этап E: иконка омонимов в обучении (R5)

Ставится **после** D10_app_server_stars_v1. Только приложение.

## Что делает

- **Иконка.** В строке инструментов карточки обучения (рядом с 💡 и 360) появляется 🟣 с числом. Число — сколько ещё карточек с той же леммой:
  - другие части речи (brenne — глагол / сущ.);
  - вторые карточки той же части речи (styr, være II / III).
  Если таких карточек нет, иконки нет.
- **По нажатию — список.** Строки «brenne — іменник · дрова», порядок: глагол, сущ., прил., наречие. Номера статей не показываются.
- **По нажатию на строку** раскрываются её перевод, пример и 💡 с уровнем этой карточки (звёзды сервера).
- Только чтение из `lexemes`, кэш на сессию. Если прочитать не удалось, иконки просто нет.

**Не входит:** переход в саму карточку внутри обучения. Тренировка идёт по своему списку, поэтому соседняя карточка раскрывается прямо в окне. Если нужен полный переход, скажите.

## Порядок

1. Установка:
   ```powershell
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\D10_homonym_icon_v1.zip" -DestinationPath "$env:USERPROFILE\Downloads" -Force
   ```
   ```powershell
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\D10_homonym_icon_v1\install_d10_homonym_icon.ps1"
   ```
2. Проверка сборки:
   ```powershell
   npx expo export --platform android
   ```
3. Сборка или `eas update`, как обычно.
4. В обучении на карточке være, like или brenne: 🟣 с числом → список → раскрыть строку.

## Откат

Вернуть `TrainingMeta.tsx` из `*.d10-homonym-icon.bak` и удалить `components/HomonymsButton.tsx`.
