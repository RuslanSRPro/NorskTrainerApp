# Purpose

Welcome to the Norsk Trainer Design Documentation.

This section defines how the application should look, feel and behave.

It contains the official product, UX and visual specifications used during development.

The goal of this documentation is to ensure a consistent user experience across the entire application.

---

# Design Philosophy

Norsk Trainer is designed to feel calm, modern and intuitive.

The interface should never compete with learning.

Instead, it should quietly guide the user towards their next learning activity.

Every screen should answer one simple question:

**"What should I do next?"**

---

# Design Goals

The design system is based on the following goals:

* Reduce cognitive load.
* Keep the interface clean.
* Prioritize learning over decoration.
* Make every interaction predictable.
* Support personalization.
* Create a premium experience inspired by Apple platforms.

# Current Design System

The current design language consists of:

## Vision-style Interface

Modern Apple-inspired interface with clean hierarchy.

---

## Glass UI

Reusable glass components.

Examples:

* GlassCard
* GlassButton
* GlassInput
* Bottom Sheets

---

## Floating Navigation

Floating glass Tab Bar.

Thumb-friendly interaction.

---

## Themes

Supported themes:

* Light
* Dark
* Turquoise
* Purple

---

## Wallpapers

Supported wallpaper types:

* Mountains
* Fjords
* Aurora
* Forest
* Winter
* Custom User Wallpaper

---

## Core Principles

Every new screen should follow these principles:

* One primary purpose.
* One primary action.
* Minimal scrolling.
* Automatic saving where appropriate.
* Consistent interaction patterns.
* Calm visual hierarchy.
* Beautiful but functional.

---

# Documentation Rules

Every design document should answer:

* Why does this exist?
* What problem does it solve?
* How should it behave?
* Which principles does it follow?

Documentation should explain **why**.

Implementation should explain **how**.
