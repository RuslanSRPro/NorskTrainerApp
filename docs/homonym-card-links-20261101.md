# Прямые связи омонимов и список Liquid Glass

Раньше HomonymsButton при монтировании искал до 12 карточек по лемме, затем отдельно
загружал их канонические переводы. Иконка зависела от завершения двух запросов и исчезала при ошибке.

Теперь каждая lexemes-карточка хранит homonym_card_ids (ID остальных карточек) и
homonym_card_count (количество всей группы, включая себя). Состав группы соответствует прежней
политике: одинаковая лемма без expression и excluded; разные части речи и омографы сохраняются.
Начальные связи заполнены; INSERT/DELETE/изменение lemma,pos,dictionary_status обновляют обе стороны.
Счётчик и список IDs меняются вместе; блокировка группы защищает от параллельных добавлений.

services/api.ts получает IDs вместе с карточкой. get_homonym_cards_v1 читает сведения по явным ID,
а не ищет по лемме, с каноническими переводами. Запрос выполняется пакетами по 200 в общей загрузке
карточек, параллельно с формами, примерами и основными переводами. Циклического получения соседей нет.
При открытии карточки и списка омонимов HomonymsButton не делает сетевых запросов.
Ошибка пакетной загрузки не убирает иконку; окно предлагает обновить обучение.

Окно и строки используют GlassOverlay, цвета useTheme, безопасные отступы экрана и прокрутку
списка; кнопка закрытия остаётся вне прокрутки. Открытие полной карточки сохранено.

Проверено: у reise noun/verb IDs взаимные, два канонических перевода получены.
SQL rollback-тест проверяет число, отсутствие ссылки на себя, удаление исключённого соседа,
обновление прежней группы и переименование. На iPhone итоговый вид и время полной загрузки
обучения ещё не измерялись; устранены запросы конкретно из кнопки, остальные загрузки обучения сохранены.
