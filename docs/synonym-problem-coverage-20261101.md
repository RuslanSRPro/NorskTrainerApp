# Проблемные карточки и обновление зависимых синонимов

## Найденные причины
- Старые RPC ограничивали список внутри базы 1000 строками, приложение брало только первые 300.
- Карточка считалась переведённой при наличии любого одного языка.
- Активная отметка AI/Lexin могла не показываться, если перевод и пример уже существовали.
- Кандидаты без карточки группировались по тексту, типу И причине; две причины давали две строки с одинаковым ключом интерфейса.
- Обновление синонимов пропускало deferred_depth/not_dispatchable и пары без заполненных target_entity_ids.

## Исправлено
- private.d10_problem_cards_all_v4: полный набор без внутреннего ограничения; оба языка обязательны;
  существующие learning-карточки и связанные с каталогом выражений карточки; сохранены family_360 и состояния синонимов.
- Текущие отметки AI и Lexin учитываются даже у карточки с переводом/примером; причины видны в интерфейсе.
- d10_problem_cards_v4(limit,offset): страницы со стабильным порядком и точным общим счётчиком.
  В приложении кнопка «Показати ще», объединение по ID; при открытии список обновляется.
- d10_synonym_unresolved_v2: одна строка на нормализованный текст и тип, все candidate_ids/родители сохраняются;
  неактивные источники исключены. API читает все страницы.
- prepare_for_job: после успешного анализа готовая подтверждённая карточка с двумя переводами
  возобновляет уже известные отложенные пары к ней; поиск также по тексту/типу, а не только старым ID.
  Новые дочерние jobs здесь не создаются. Перепроверка по существующему snapshot/hash/history механизму.

## Проверено
- Полный список до добавления остальных review-меток: 1852 строки и 1852 разных ID.
- frisk noun без переводов найден; frisk adjective имеет переводы и отдельную причину family_360.
- Существующий завершённый аудит søppel возобновил входящие avfall → søppel и boss → søppel;
  обе пары впоследствии verified_synonym. Массовый сбор не включался.
- synonym_problem_coverage.test.sql (rollback): уникальность, frisk, søppel, отложенная входящая пара
  без target IDs, отсутствие новых jobs — PASS.
- synonym_unresolved_dedup.test.sql (rollback): две причины объединены, оба ID сохранены — PASS.
- problem_active_review_marks.test.sql (rollback): полностью переведённая карточка с активной
  отметкой проверки остаётся в общем списке, без дублей — PASS.
- 20 существующих Node-тестов верификатора и показа синонимов — PASS.
- Проверка синтаксиса изменённых TypeScript/TSX пройдена; на телефоне интерфейс ещё не проверен.

## Границы
Омонимы с разными ID не объединяются по написанию. Исторический отчёт старой задачи сохраняет её
замечания, общий список отражает текущее состояние. Старое отсутствие перевода у søppel ретроспективно
не доказано: карточка уже обновлена. Сам парсер выражений и допуск выражений этим изменением не исправляются.
Карточка выражения без связанного lexeme_id пока относится к списку нерешённых кандидатов,
а не к списку карточек с кнопкой повторного анализа по lexeme_id.
