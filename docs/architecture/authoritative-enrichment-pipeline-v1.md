# Authoritative Enrichment Pipeline V1

## Purpose

Authoritative Enrichment Pipeline is the central orchestration layer for lexical verification and enrichment.

It combines:

* authoritative sources
* internal analytical classification
* verification status resolution
* semantic enrichment

The goal is to separate:

1. source evidence
2. analytical interpretation
3. verification decisions

These layers must never be mixed.

---

# Layer 2 — Internal Analytical Model

This layer is generated by Norsk Trainer.

It is not copied from any dictionary.

---

## Expression Structure

Field:

```text
expression_structure
```

Values:

```text
particle_verb
prepositional_verb
support_verb_construction
reflexive_construction
multiword_fixed
```

Purpose:

Describe grammatical structure.

Examples:

```text
ta opp
  particle_verb

vente på
  prepositional_verb

ta hensyn til
  support_verb_construction
```

---

## Expression Semantics

Field:

```text
expression_semantics
```

Values:

```text
idiom
collocation
conversation_phrase
discourse_marker
```

Purpose:

Describe semantic behaviour.

Examples:

```text
ha is i magen
  idiom

ta hensyn til
  collocation

ha det bra
  conversation_phrase
```

# Layer 3 — Verification Resolution

Combines evidence from all authoritative sources.

Field:

```text
expression_review_status
```

Values:

```text
verified
partial
unverified
disputed
```

Rules:

verified
Multiple authoritative sources agree.

partial
At least one authoritative source confirms.

unverified
No authoritative confirmation.

disputed
Sources provide conflicting evidence.

# Layer 5 — Master Orchestrator

Future function:

```text
authoritative-enrichment-pipeline
```

Responsibilities:

1. Run all source pipelines.
2. Collect evidence.
3. Update source status fields.
4. Run analytical enrichment.
5. Resolve verification status.
6. Produce final catalog state.

This becomes the single entry point for large-scale enrichment.
