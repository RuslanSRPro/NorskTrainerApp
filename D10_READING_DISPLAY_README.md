# D10 — режим «Чтение»: выбор слов, переводы и примеры

Патч только приложения: нет миграции, ничего не деплоится в Supabase.

## Что исправлено

1. **Слова не попадают в обучение сами по себе.**
   Раньше любой анализ текста добавлял каждое слово текста, которое есть в базе, в обучение пользователя (`learning_progress`). Поэтому при следующем анализе все слова становились зелёными («выучено»).
   Теперь при чтении обновляются только счётчики встреч у слов, которые уже есть в обучении.
   Найдено попутно: для слов в обучении каждое чтение сбрасывало прогресс повторений (status = New, repetitions = 0, интервал). Теперь прогресс тренировки не трогается.
2. **Режим «Чтение» — пишется только выбранное.**
   - 🔴 Слово не в базе → после «💾 Сохранить» уходит в базу (проверка, обогащение). После обработки, когда появится ✅, оно добавляется в обучение.
   - 🟡 Слово в базе, но не в обучении → теперь его можно отметить. После «💾 Сохранить» оно сразу добавляется в обучение. В списке кандидатов в режиме чтения теперь есть и такие слова, а не только выражения.
   - Слова, уже добавленные в обучение, отметить нельзя.
   - Режим «Аудит» работает как раньше.
3. **Переводы.**
   - Корневое слово Lexeme360, карточка слова и превью: украинский и английский перевод, каждый на своей строке.
   - В карусели убраны метки «UK:» и «EN:».
4. **Примеры.**
   - Корневое слово Lexeme360: пример раньше не показывался никогда — фильтр ждал колонку `language_code`, которой нет в ответе `get_lexeme360_examples_v1`. Теперь показываются собственный пример корня и его украинский перевод, если он есть.
   - Тренировка:
     - карточки: после ответа показывается украинский перевод примера;
     - выбор, ввод, формы: после ответа показываются пример и его перевод.

## Установка

1. Скопировать папку патча в «Загрузки».
2. Из корня проекта:

   ```
   powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\D10_reading_display_v1\install_d10_reading_display.ps1"
   ```

3. Перезапустить Expo.

Откат: вернуть файлы из `*.d10-reading-display.bak`.

## Проверка

1. «Чтение» → анализ нового текста, который вы ещё не анализировали.
   - Слова, которые уже в базе, остаются 🟡, а не 🟢.
   - Слова, которых нет в базе, 🔴.
   - Слова, попавшие в обучение при прошлых чтениях (например, из «Er tiden. Tar mat»), останутся 🟢, пока эти строки не убраны (см. 57).
2. Отметить одно 🟡 и одно 🔴 → «💾 Сохранить».
   - 🟡 сразу становится зелёным («в обучении»).
   - Для 🔴 появляется ⏳. После ✅ список перечитывается, и слово добавляется в обучение.
3. Открыть «være» (360): под словом «бути» и «be», пример под заголовком.
4. Тренировка: после ответа виден пример с переводом, если он есть у слова.
